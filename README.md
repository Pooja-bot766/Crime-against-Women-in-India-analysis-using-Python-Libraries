# Crime-against-Women-in-India-Analysis-using-Python-Libraries

Data analysis and visualization of crimes against women in India using Python libraries to identify trends, patterns, and insights through Exploratory Data Analysis (EDA).

This project focuses on analyzing crimes against women in India using Python-based data analysis and visualization techniques. The objective is to examine crime trends, identify patterns, perform state-wise and year-wise analysis, and generate meaningful insights through data-driven exploration.

Using real-world crime datasets, the project applies data cleaning, preprocessing, statistical analysis, and visualization methods to understand the distribution and nature of crimes against women across different states and regions of India.

## Objectives
- Analyze crime trends against women in India.
- Perform state-wise and year-wise crime analysis.
- Identify regions with higher crime rates.
- Compare different categories of crimes against women.
- Visualize crime patterns using charts and graphs.
- Generate meaningful insights through data analytics.

## Technologies Used
- Python
- Pandas – Data manipulation and analysis
- NumPy – Numerical computations
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization
- Jupyter Notebook

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- State-wise Crime Analysis
- Year-wise Trend Analysis
- Data Visualization using Charts and Graphs
- Pattern and Trend Identification
- Insight Generation from Datasets

## Project Outcomes
- Identified crime trends across different states and years.
- Highlighted regions with comparatively higher crime rates.
- Provided visual representations of crime distribution and patterns.
- Generated insights that can support awareness, research, and policy discussions.
- Demonstrated the application of Python libraries for real-world data analysis and visualization.

## Conclusion
This project showcases the use of Python for analyzing social issues through data analytics. By transforming raw crime data into meaningful visualizations and insights, the analysis helps improve understanding of crimes against women in India and supports data-driven decision-making.
